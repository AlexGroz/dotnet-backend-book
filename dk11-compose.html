Глава 11. Compose: весь стек одной командой

API + PostgreSQL + healthcheck и depends_on — и почему это не «прод-оркестратор»

основная глава

Глава в работе

План главы:

  • Что такое compose.yaml и как он заменяет десяток docker run с флагами.
  • Полный пример для .NET: сервис api (build, ports, environment), сервис db (postgres:16, том, healthcheck pg_isready).
  • depends_on с condition: service_healthy — и почему без условия он не спасает от «база ещё стартует».
  • Команды: up -d --build, ps, logs -f api, exec db psql, down, down -v.
  • Профили, .env, переопределение файлов (compose.override.yaml).
  • Границы: одна машина, нет rolling update и самовосстановления — что дальше (глава 15).
