Глава 2. Управление памятью и Garbage Collector

Почему под нагрузкой важна не «память вообще», а скорость создания объектов — и как это влияет на CPU и задержки.

Стек и куча

  • Стек — быстрое место для локальных переменных и вызовов методов. Освобождается автоматически при выходе из метода.
  • Куча — где живут объекты (экземпляры классов, массивы, строки). За её очистку отвечает Garbage Collector (GC).

Поколения и почему они дешёвые

GC поколенческий: он предполагает, что большинство объектов умирает молодыми. Поэтому объекты делят по времени жизни:

ПоколениеЧто тамСтоимость сборки
Gen0Молодые объекты (ваши DTO, строки на запрос)Часто и дёшево
Gen1Пережившие одну сборкуДёшево
Gen2Долгоживущие (кэши, синглтоны)Редко и дороже; может давать паузы
LOHКрупные объекты (массивы от ~85 КБ)Собирается вместе с Gen2
Главная мысль

Gen0-сборка дешёвая, потому что почти все молодые объекты мертвы. Но каждый запрос создаёт мусор (DTO, строки, списки). Чем больше мусора в секунду — тем чаще Gen0 — тем больше CPU уходит на GC, а не на полезную работу.

Server GC vs Workstation GC

Для серверных приложений (ASP.NET Core) обычно включён Server GC: отдельная куча и поток GC на ядро. Это повышает пропускную способность ценой большего потребления памяти.

<PropertyGroup>
  <ServerGarbageCollection>true</ServerGarbageCollection>
</PropertyGroup>

Что создаёт «лишний» мусор

ИсточникЧем заменить
Boxing (упаковка struct в object)generic-коллекции: List<int>
Конкатенация строк в циклеStringBuilder
Исключения как поток управленияметоды Try* (TryParse)
Крупные временные буферыArrayPool<T>

Простой пример: убрали boxing и мусор от строк

// ✘ ArrayList упаковывает каждый int в объект
var list = new ArrayList();
list.Add(42);

// ✔ generic-коллекция: int хранится как int
var list2 = new List<int>();
list2.Add(42);

// ✘ конкатенация в цикле: строка на каждой итерации
string s = "";
for (int i = 0; i < 1000; i++) s += i + ",";

// ✔ один буфер
var sb = new StringBuilder(4096);
for (int i = 0; i < 1000; i++) sb.Append(i).Append(',');
var result = sb.ToString();
★ Что запомнить из главы

Под нагрузкой важна скорость аллокаций, а не объём памяти. Gen0 дешёв, Gen2 и LOH — дороже. Практический вывод: не создавать лишний мусор на горячем пути. Инструменты для этого — в главе 13, измерение — в главе 14.
