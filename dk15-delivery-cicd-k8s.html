Глава 15. Поставка: CI/CD, теги и граница с Kubernetes

Сборка в пайплайне, latest и digest, и что Docker уже не делает

основная глава

Глава в работе

План главы:

  • Пайплайн: dotnet test → docker build → docker push с тегом по git SHA; кэш сборки в CI (registry cache, inline cache).
  • Схема тегов: semver, SHA, latest; почему в проде фиксируют digest и как откатываться.
  • dotnet publish /t:PublishContainer — сборка образа без Dockerfile и без Docker-демона (кратко).
  • Что дальше: Kubernetes Deployment/Service/Ingress, probes, HPA; Helm; где живут секреты.
  • Docker Compose против Kubernetes: таблица — одна машина против кластера, нет rolling update против есть.
  • GitOps и откат: «предыдущий тег» как самый быстрый способ вернуть рабочую версию.
