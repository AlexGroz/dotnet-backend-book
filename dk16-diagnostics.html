Глава 16. Диагностика: OOMKilled, коды выхода, inspect

Контейнер не стартует или умер — алгоритм разбора по шагам

основная глава

Глава в работе

План главы:

  • Порядок действий: docker ps -a → logs → inspect .State → сеть → файлы.
  • Коды выхода: 0, 1, 127 (команды нет), 137 (SIGKILL/OOM), 143 (SIGTERM) — что каждый значит.
  • Как отличить OOM от ручного kill: State.OOMKilled, лимит памяти, docker stats.
  • Сеть: getent hosts db, проверка порта изнутри, docker network inspect.
  • Файлы и права: docker diff, bind mount, UID non-root.
  • Образ: exec format error, неверный ENTRYPOINT, отсутствующая Dll, порт внутри не тот.
