# Backend на .NET: от кода до высокой нагрузки

Книга-конспект для подготовки backend-разработчика (.NET). Уровень: **продвинутый middle**.

**Читать (веб-версия):** `https://AlexGroz.github.io/dotnet-backend-book/`

## Содержание

**Часть I. Фундамент: язык и память**
1. Как .NET выполняет код: CLR, JIT, типы
2. Управление памятью и Garbage Collector

**Часть II. Исполнение: потоки и асинхронность**
3. Потоки и пул потоков
4. Асинхронность: async/await и Task

**Часть III. Структура приложения**
5. Внедрение зависимостей и жизненные циклы
6. Конфигурация и опции
7. HTTP-конвейер и маршрутизация
8. Логирование и наблюдаемость

**Часть IV. Данные и интеграции**
9. Доступ к данным: EF Core и SQL
10. Кэширование
11. Сетевые вызовы и устойчивость
12. Очереди и фоновая обработка

**Часть V. Производительность и эксплуатация**
13. Аллокации и низкоуровневая оптимизация
14. Измерения, профилирование, нагрузка
15. Масштабирование и отказоустойчивость

**Часть VI. Практика**
16. Сквозной разбор: высоконагруженный эндпоинт
17. Миграция legacy: .NET Framework → .NET Core
18. Как отвечать на интервью

## Статус

Книга в работе. Готовы главы **1–5**; остальные — заготовки, будут дополняться постепенно.
