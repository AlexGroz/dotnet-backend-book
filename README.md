# Backend на .NET: от кода до высокой нагрузки

Учебник для backend-разработчика на .NET. Уровень: **продвинутый middle**.

Каждая тема опирается на предыдущие, а перед основными темами идут **подводящие главы** — без них
тему не понять.

**Читать (веб-версия):** `https://AlexGroz.github.io/dotnet-backend-book/`
